# CI/CD Labs

Repositorio de laboratorios prácticos del módulo **Entornos de Integración y Entrega Continua (CI/CD)**.

## Sobre este proyecto

Este repositorio contiene el desarrollo progresivo de un pipeline de Integración Continua,
construido paso a paso a lo largo de los laboratorios del módulo. Cada laboratorio amplía
la funcionalidad del pipeline anterior, incorporando nuevas prácticas de CI/CD.

## Objetivo

Comprender de forma práctica el funcionamiento de un pipeline moderno: desde su estructura
básica (Pipeline as Code) hasta flujos colaborativos con ramas, Pull Requests, compilación,
pruebas automatizadas, controles de seguridad y despliegue.

| Laboratorio | Descripción |
